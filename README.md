# The Pitstop Passport - Cucumber BDD Tests

Този проект съдържа автоматизирани Behavior-Driven Development (BDD) тестове за функционалностите на "The Pitstop Passport", реализирани с Java, Maven, JUnit 5 и Cucumber.

## 🚀 Инструкции за стартиране

### Чрез терминал (Maven)
1. Уверете се, че имате инсталирани Java и Maven.
2. Отворете терминала в основната директория на проекта.
3. Изпълнете следната команда:
   ```bash
   mvn test
